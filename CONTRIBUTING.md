# Contributing

The most useful contribution is **a ladder for your stack**. If you shipped something on a stack `ladders.md` doesn't cover well (Rails, Laravel, Shopify apps, Chrome + Firebase, Godot, Unity, whatever), you already know where the scary parts are.

## Add or improve a ladder

1. Edit [`skills/im-scared/ladders.md`](skills/im-scared/ladders.md). Add a `## Your stack` section, or improve an existing one.
2. Write it as changes to the universal spine (which rungs change, get added or get dropped), not a full copy.
3. Keep every rung to 10 minutes or less, tagged `you`, `agent` or `both`.
4. Put the hidden gotchas in. Things like "set the production OAuth callback URL" or "Steam takes 30 days" are the whole point.
5. If a rung costs money, say how much.

## Other changes

- **The nudges feel naggy, or too quiet?** Open an issue describing what happened. The rules live in the "Rules for the agent" section of [`templates/LAUNCH.md`](skills/im-scared/templates/LAUNCH.md).
- **Interview too long?** Open an issue saying which question felt useless.
- **Works (or breaks) in Codex, Cursor or Gemini CLI?** Please report it either way. Those agents have had the least testing.

Keep changes small. One ladder or one fix per PR is perfect.
